# Advanced materials: bending stiffness and anisotropy (issues #31 / #86)

Issue #31 established the reference-model physics and stability result for a
4th-order **bending-stiffness** term (bars, plates, bells) plus **anisotropic**
propagation. Issue #86 now integrates the bending term into the production RTL
for both spatial and time-multiplexed meshes. The floating-point study remains
[`model/StiffMesh2D.m`](../model/StiffMesh2D.m) +
[`model/stiffness_study.m`](../model/stiffness_study.m); the production fixed-point
control mapping is independently regenerated by
[`model/stiffness_reference.py`](../model/stiffness_reference.py).

## The equation

The legacy/zero-STIFFNESS membrane is `u_tt = c^2 ∇^2 u`. Adding bending
stiffness and anisotropy:

```
u_tt = cx^2 u_xx + cy^2 u_yy  -  kappa^2 (u_xxxx + 2 u_xxyy + u_yyyy)  - 2 sigma u_t
```

- `cx, cy` : wave speeds along x / y. `cx = cy` is isotropic; `cx != cy` is an
  anisotropic membrane (an "oval drum": the mode frequencies split).
- `kappa` : bending-stiffness coefficient. The biharmonic term `∇^4 u` is the
  thin-plate / stiff-bar operator; it makes the medium **dispersive** (higher
  spatial frequencies travel faster), which stretches the partials sharp of a
  harmonic series, the inharmonic bar/bell character.

## Discretisation

Second differences (existing) plus the biharmonic. With `k = 1/fs` the time step
and `h` the spatial step, the explicit centred update is

```
u^{n+1} = a0 ( 2u - sigk1 u^{n-1} + g2x Dxx(u) + g2y Dyy(u) - mu2 Biharm(u) )
```

with the dimensionless coefficients

```
g2x = (cx k / h)^2      g2y = (cy k / h)^2      mu2 = (kappa k / h^2)^2
```

and the stencils (`1/h^4` folded into `mu2`):

```
Dxx = uE + uW - 2u                              (3-point)
Dyy = uN + uS - 2u                              (3-point)
Biharm = 20u - 8(N+S+E+W) + 2(NE+NW+SE+SW) + (NN+SS+EE+WW)   (13-point)
```

`Biharm` is the discrete `(∇^2)^2`: a **13-point** stencil that reaches two cells
out (the second ring `NN/SS/EE/WW`) and to the diagonals. Setting `mu2 = 0` and
`g2x = g2y` recovers the current 5-point membrane exactly.

## Stability (von Neumann)

Substitute `u ~ z^n e^{i(bx x + by y)}` and let `sx = sin^2(bx h/2)`,
`sy = sin^2(by h/2)`, each in `[0,1]`. The stencil Fourier symbols are

```
Dxx -> -4 sx     Dyy -> -4 sy     Biharm -> +16 (sx + sy)^2
```

(the biharmonic symbol is the square of the Laplacian symbol, since it is
`(∇^2)^2`). The update's characteristic equation is `z^2 - (2 - Q) z + 1 = 0`
with

```
Q = 4 (g2x sx + g2y sy) + 16 mu2 (sx + sy)^2   >= 0
```

Roots stay on the unit circle (stable, non-growing) iff `0 <= Q <= 4` for all
`sx, sy`. `Q` is maximised at `sx = sy = 1`:

```
Q_max = 4 (g2x + g2y) + 64 mu2   <=  4
```

giving the **stability condition**

```
(g2x + g2y) + 16 mu2  <=  1
```

Sanity checks:
- membrane (`mu2 = 0`, `g2x = g2y = g^2`): `2 g^2 <= 1`, i.e. `g^2 <= 1/2`,
  exactly the CFL limit Courant already uses (`gamma2_max = 0.451`, issue #3);
- pure plate (`g2x = g2y = 0`): `mu2 <= 1/16`.

**The stiffness term tightens CFL**: every unit of `16 mu2` is stolen from the
wave headroom `(g2x + g2y)`, so a stiffer medium must run a lower wave speed for
the same grid.

### Confirmed against the model

`stiffness_study.m` sweeps `mu2` at fixed `g2x = g2y = g^2` and compares the
empirical stable maximum to the predicted `mu2 = (1 - 2 g^2)/16`:

| `g^2` (each axis) | predicted `mu2_max` | empirical `mu2_max` | match |
| --- | --- | --- | --- |
| 0.05 | 0.05625 | 0.05625 | yes |
| 0.10 | 0.05000 | 0.05000 | yes |
| 0.20 | 0.03750 | 0.03750 | yes |

The closed-form boundary is exact to the sweep resolution.

### Timbre (audio)

`stiffness_study.m` renders `model/outputs/{membrane,stiff_plate,anisotropic}.wav`.
The measured low partials show the expected behaviour: adding stiffness stretches
the partial ratios sharp (dispersion -> inharmonic bar/bell), and anisotropy
(`cx != cy`) splits the degenerate membrane modes into distinct frequencies (the
"oval drum"). The wavs are git-ignored artefacts; regenerate with
`octave-cli --eval "stiffness_study"`.

## Production RTL integration (#86)

### Control encoding and stability

STIFFNESS is stored in register 5 bits 23..16 and is latched per voice. The
production mapping deliberately makes zero an exact legacy bypass:

```
mu2 = STIFFNESS / 4096
gamma2_max_eff = min(gamma2_max, 0.5 - STIFFNESS/512)
```

The second expression is the studied bound specialized to RADIAN's current
anisotropy operator, which redistributes X/Y propagation while preserving
`g2x+g2y = 2*gamma2`. Thus every nonlinear local `gamma2` value is clamped
before the update can violate `(g2x+g2y)+16*mu2 <= 1`.

### Datapath

`physical_pkg.biharmonic_term` evaluates the 13-point operator with adds and
shifts. `physical_pkg.stiffness_term` implements `mu2*Biharm` as an eight-bit
shift/add multiply followed by the same round-then-shift convention as
`mul_coeff`; it therefore does not allocate another DSP multiplier.
`node_element` subtracts that term in stage 3 and keeps its four-clock
pipeline latency.

The fixed-boundary case uses zero padding outside the surface, matching the
reference study. Runtime free/compliant boundaries mirror the inward sample and
apply the existing RIM reflection law to the wider stencil as well.

### Spatial and time-multiplexed backends

The spatial backend forms the wider stencil directly from the live node grid.
The TDM backend avoids eight new simultaneous memory reads: four gather states
fetch two diagonal/second-ring taps per clock, followed by the normal update
state. These gather states are completely bypassed when STIFFNESS=0, preserving
legacy membrane timing.

For the production 8x8 TDM grid a nonzero-stiffness mesh step is **322 system
clocks**; at OS=4 that is 1288 mesh clocks per audio frame before the small
`mesh_resonator` handshake overhead, below the 2083-clock budget at
100 MHz / 48 kHz.

### Verification

- `model/stiffness_reference.py` independently regenerates the committed
  Q1.23 golden trace using the production 8-bit control encoding.
- `stiffness_tb` compares the TDM output to that golden trace, requires
  spatial/TDM bit equality, exercises fixed and free/compliant boundaries,
  checks the high-stiffness CFL clamp, and pins the 322-clock TDM step.
- The analytic discrete-mode check confirms dispersion rather than a global
  pitch shift: with STIFFNESS=0x60, mode (1,1) rises about **3.5%** while mode
  (4,4) rises about **41.9%**.
- Existing membrane golden tests remain bit-exact at STIFFNESS=0.

### Open-source synthesis snapshot

Using GHDL 6.0's built-in VHDL synthesis followed by Yosys 0.68
`synth_xilinx -family xc7`:

| block | DSP48E1 | LUT1..6 | FF |
| --- | ---: | ---: | ---: |
| `node_element` with runtime STIFFNESS | **18** | 1,911 | 480 |
| 8x8 `grid_mesh_tdm` with runtime STIFFNESS | **18** | 28,575 | 3,615 |

The binding result is that STIFFNESS adds **no DSPs** to the mesh. The LUT number
is intentionally not treated as a board-fit verdict: this open-source flow
expands the multi-read TDM state into mux fabric, and the wider plate stencil
makes that pessimism more visible. Vivado implementation on the XC7A50T remains
the physical resource/timing sign-off.

## Status

The #31 recommendation is now implemented rather than conditional. RADIAN can
continuously move from the legacy tension-dominated membrane at STIFFNESS=0
toward dispersive stiff sheets/plates while retaining the same preset format and
physical panel hardware.
